# Kyle — Irrigation System Presentation

A standalone visual presentation explaining well supply, underground storage, pumping, automatic filtration, smart controls and landscape irrigation.

Use the chapter buttons to move through the system. Select a component for its explanation, or drag the model to rotate it.

This static site runs directly on GitHub Pages. No build step or API keys. Project photography and the original case study are excluded.

Wi-Fi and weather-based control describe the proposed system; final features are confirmed during design.
